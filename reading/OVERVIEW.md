# Reading: overview

All Reading results, band estimates and errors by task and question type. Updated after every test.

## How tests are scored
Reading has two modules (about 35 + 15 questions), and some questions in the first module are unscored. The result is the number of correct scored items, and the band is read from the test's own table or from ETS's Table 3 in `ets-format.md`. It is always an estimate.
