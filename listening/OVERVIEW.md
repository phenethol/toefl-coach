# Listening: overview

Listening test results, band estimates and error types. Updated after every test.

## How tests are scored

- The tests follow the format in ETS's *Updated TOEFL iBT Test Overview*:
  - **Listen and Choose a Response:** you only hear the sentence and choose from 4 written replies.
  - **Listen to a Conversation:** a conversation, then 2 questions.
  - **Listen to an Announcement:** a 40–85 word announcement, then questions.
  - **Listen to an Academic Talk:** a 100–250 word talk, then 4 questions.
- Each recording plays only once.
- Every test has **30 scored items** (the raw score range on the ETS test is 0–30), in two stages: the first is of mixed difficulty, the second is an upper module.
- **Band estimate:** raw /30 read from ETS's Table 3 (Listening column). The real test is adaptive and scored differently, so this is a rough estimate.
